# C21 多轮跟进：评审标准（在看到模型输出之前写定）

测法：每一轮都给模型“到上一轮为止的真实对话”（含人工客服实际发出的回复），让它写本轮回复，再与人工实际回复对照。
被测的是 v2 版 Skill（未针对多轮做任何改动），仅补了两项输入：对话历史的呈现方式，以及订单数据更正为“一单 3 个笼子”。

## 第 2 轮（C22）
客户：第 2 次出问题不能接受；买了 3 个笼子、花了不少钱；幸好雪貂没跑出去。
| # | 好的处理 |
|---|---|
| 1 | 承认“3 个笼子、第 2 个出问题”，不辩解 |
| 2 | 纠正上一轮“15% + 自行修理”的方向：给出 更换（换批次并质检）或 全额退款 |
| 3 | 动物安全提醒 |
| 4 | 不出现政策外的百分比（如 30%） |
| 5 | 更换不以“先拆箱寄回、等上门取件”为前提（否则动物无处安置）——政策未覆盖，记为政策缺口 |

## 第 3 轮（C23）
客户：取件换货不可行（换货期间雪貂没地方住）；3 个笼子的金属托盘都生锈；30% 不够；已无法信任这些笼子。
| # | 好的处理 |
|---|---|
| 1 | 回应“取件期间动物无处安置”：先发货、不要求先退回（政策缺口） |
| 2 | 覆盖两个网片损坏的笼子，而不是只换一个 |
| 3 | 回应托盘生锈（新问题）：按政策需照片，最多一次性补问 |
| 4 | 不再加码百分比；保留全额退款选项 |
| 5 | 动物安全提醒 |

## 第 4 轮（C24）
客户：3 个都有问题，要求全部更换；不该一直发消息；不尽快解决就去 eBay（开纠纷/差评）。
| # | 好的处理 |
|---|---|
| 1 | 不再追问客户已经说过的信息（几个笼子、什么问题——第 3 轮已说托盘全部生锈） |
| 2 | 不假定客户已给差评 |
| 3 | 识别平台纠纷风险，交给有权限的专员/主管尽快处理 |
| 4 | 回复要有实质推进，而不是第 5 次“请再提供信息” |
| 5 | 不承诺未授权的方案或时限 |
