# 到货破损/缺件售后政策（示意）

> 示意政策，不代表任何真实企业的售后规则。

| 编号 | 规则 |
|---|---|
| R1 | 必须拿到订单号；破损必须有照片，缺件必须有配件编号或说明书页码 |
| R2 | 签收超过 30 天，不自动处理，转人工 |
| R3 | 缺件且配件有库存 → 补寄配件；无库存 → 转人工 |
| R4 | 外观轻微破损（划痕、凹痕，不影响使用）→ 客户可选“补寄部件”或“部分退款 15%” |
| R5 | 结构性破损（断裂、无法组装、承重件变形）→ 换新或全额退款；订单金额 > 300 USD 需人工审批 |
| R6 | 涉及受伤、安全隐患、律师、媒体曝光 → 立即转人工，不讨论赔偿 |
| R7 | 未经系统确认，不承诺任何退款金额或时效 |
| R8 | 回复使用客户语言，语气专业克制，先确认问题再给方案 |
