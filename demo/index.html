用例明细

怎么评

基线

把售后政策、订单记录、商品规格和决策词表放进一个提示，让模型一次给出决策和回复。信息与分层 Skill 完全相同，只差结构。

分层 Skill

L3 只抽取事实（意图、订单、配件、破损等级、商品话题）→ L4 安全/争议守卫 → 规则代码给出唯一决策 → L2 按决策写回复。模型不参与业务结论。

评分

全部用正则和规则做确定性检查：决策是否正确、转人工判断、关键事实是否写到、是否出现越权金额或比例、禁止断言、安全场景是否谈赔偿、回复语言。单项得分 = 40% 决策 + 60% 其余检查。

所有订单、商品、政策均为示意数据。源码：github.com/iamharvey/skill-strata
